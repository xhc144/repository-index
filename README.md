## 访问与下载

- 本目录及所列仓库均为私有仓库。请登录具有对应仓库访问权限的 GitHub 账号；获得本目录权限不会自动获得其他仓库权限。
- PDF、ZIP、APK 和 Blender 文件从对应文件页或 Release 页面下载。链接打不开时，先检查登录状态和目标仓库权限。
- 页数、题数、版本与整理进度由各项目自己的 README 维护，本目录保留稳定入口。原始资料与第三方内容仍受各自版权和许可约束。
